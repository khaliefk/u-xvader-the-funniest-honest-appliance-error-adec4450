A make.fun entry: one line, the funniest honest error message an
appliance could show. A fridge, door left open for seven minutes, flat
and put-upon about it.

## The entry

> ERROR 04: Door open 7 minutes. I am a fridge, not a window. Your milk is now 12 degrees and judging you too.

108 characters, inside the 200-character gate.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory). Standard library only, no network, no input files.
